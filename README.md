# Automotive Manufacturing Application - Performance Testing with JMeter 🚗

This project simulates load and stress testing on a large-scale web-based vehicle platform offering passenger and commercial vehicles (SUVs, EVs, Trucks, Buses, etc.).

## 🔍 Project Overview

- **Domain:** Automotive manufacturing (web application)
- **Team Size:** 4 QA Engineers
- **Testing Tool:** Apache JMeter
- **Test Modules:** Vehicles, Buy, Services, Experiences, Global Market, Subscribe, Lease

## 📈 Test Scenarios

| Test Type   | Users Simulated | Goal                          |
|-------------|------------------|-------------------------------|
| Load Test   | 750 Users        | Simulate normal user load     |
| Stress Test | 1000 Users       | Test upper performance limit  |

## 🔧 Tools & Technologies

- Apache JMeter
- CSV Data Config for dynamic users
- HTML & JSON-based responses validation
- Summary Reports, Aggregate Graphs, and Listeners

## 📂 Repository Contents

- `ServiceModule_TestPlan.jmx` – Main JMeter test plan
- `Vuser.csv` – Dynamic data file
